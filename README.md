# Astro Portfolio 🚀

A modern, high-performance personal portfolio built with [Astro](https://astro.build/).

## 🌟 Features

- **Astro 5** - Extremely fast, static site generator.
- **Tailwind CSS** - Utility-first CSS framework for rapid UI development.
- **Svelte & React** - Multi-framework component integration.
- **Three.js & Threlte** - 3D experiences integrated directly into the web.
- **Framer Motion & GSAP** - Smooth, complex animations and interactions.

## 🚀 Getting Started

First, clone the repository and install the dependencies:

```bash
npm install
```

Then, start the development server:

```bash
npm run dev
```

Open [http://localhost:4321](http://localhost:4321) with your browser to see the result.

## 🛠️ Scripts

- `npm run dev` - Starts the development server.
- `npm run build` - Builds the project for production.
- `npm run preview` - Previews the production build locally.

## 📂 Project Structure

- `/src/components` - UI Components (React, Svelte, Astro).
- `/src/pages` - Application routes.
- `/src/layouts` - Shared page layouts.
- `/src/assets` - Static assets like images and styles.
- `/src/content` - Content collections.
