<ProjectStandard project={frontmatter}>
This project focuses on scraping comments from YouTube videos and performing sentiment analysis using the **XLM-RoBERTa** machine learning model. It is a cutting-edge language model that excels at processing multilingual text, including Indonesian and English.

Key features include **zero-shot sentiment analysis** using a pre-trained `cardiffnlp/twitter-xlm-roberta-base-sentiment` model from Hugging Face, an advanced preprocessing pipeline that transforms emojis into text representations to retain emotional context, and a custom script for fine-tuning the model to achieve higher accuracy specifically for the YouTube domain.
